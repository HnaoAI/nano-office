# Nano Office

Traitement de texte sobre, sans publicité ni assistant IA, pour un usage familial (projet pilote).
PWA en TypeScript, React, Tiptap et Yjs. Commandes : `npm run dev`, `npm run build`, `npm run typecheck`, `npm run lint`, `npm test`, `npm run test:e2e`.

- `CLAUDE.md` : règles techniques et produit, à lire avant toute action
- `docs/contexte-produit.md` : vision, feuille de route, organisation
- `docs/regles-de-travail.md` : règles générales de travail (méthode, tests, Git, dépendances)
- `docs/analyse-2026-10-18.md` : analyse du cadrage et points à régler avant T0
- `tickets/` : un fichier par ticket
- `src/` : code de l'application (voir `src/README.md`)
- `public/icons/` : icônes provisoires de l'application installable (T0e)
- `tests/` : tests Vitest et Playwright (voir `tests/README.md`)

# T2.7 : Exporter en Word (.docx)

**Suivi** : Issue [#61](https://github.com/HnaoAI/nano-office/issues/61), le statut se lit sur le tableau Kanban
**Dépend de** : T2.5, lot D
**Taille estimée** : M
**Lot** : F. La page

## User story

En tant que membre de la famille, je veux envoyer mon document en fichier Word,
afin qu'une personne sans Nano Buro puisse l'ouvrir et le modifier.

## Critères d'acceptation

1. « Exporter en Word… » dans le groupe Fichier propose d'enregistrer `<nom du document>.docx` : un sélecteur sur
   Chrome et Edge, un téléchargement ailleurs. Le fichier `.nano` n'est jamais modifié, et le fichier courant
   reste le `.nano` : Ctrl/Cmd+S n'écrit jamais dans le `.docx`.
2. Le `.docx` s'ouvre sans erreur ni réparation dans Word (Mac et Windows), LibreOffice et Google Docs.
3. Il garde :
   - les titres 1 à 3, comme styles « Titre 1 » à « Titre 3 » de Word (pour le sommaire de Word) ;
   - le gras, l'italique, le barré, la couleur, la police et la taille ;
   - le surlignage, converti vers la couleur de surlignage Word la plus proche ;
   - l'alignement, l'interligne (T2.2), les listes à puces et numérotées avec leurs niveaux ;
   - les tableaux avec leur ligne d'en-tête ;
   - les images, avec leur taille et leur alignement ;
   - le format A4, l'orientation et les marges (T2.5).
4. **Polices** : les polices utilisées sont embarquées dans le `.docx` si la bibliothèque le permet (la licence OFL
   l'autorise), pour que le document s'affiche pareil chez la personne qui le reçoit. Sinon, seul leur nom est
   écrit, et la PR le signale.
5. Un document vide, très long (100 pages), avec accents et emojis, s'exporte sans erreur.
6. Rien ne part sur le réseau : l'export se fait dans le navigateur.

## Note technique

Bibliothèque `docx` (MIT), largement utilisée. La conversion du contenu Tiptap vers le modèle `docx` est du code
pur dans `core/`, testé sans navigateur. L'écriture du fichier passe par `storage/`.

## Hors périmètre

Ouvrir un fichier Word dans Nano Buro (import), commentaires, suivi des modifications, export ODT.
